# Hazeline Tee Calda — Portfolio Website

A responsive, animated, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, typography, colours, and animations
- `script.js` — mobile navigation, scroll reveal, and cursor glow
- `assets/appointment-setting-sample.png` — supplied Zoom screenshot used in Sample Work (if included)

## Preview locally
Open `index.html` in a browser. For a more reliable local preview, use VS Code's Live Server extension.

## Publish with GitHub Pages
1. Create a new **public** GitHub repository, for example `hazeline-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your site URL will appear in the Pages section.

## Before publishing
- Confirm the dates and job titles in Experience.
- Decide whether you want your phone number publicly visible. Remove it from the Contact section if you prefer email only.
- Review the screenshot in Sample Work and make sure you have permission to publish it.
- Consider adding a professional headshot and a downloadable PDF resume.
- Check every public contact detail for accuracy.

## Customization
Edit the text directly in `index.html`. Change colours near the top of `style.css` in the `:root` variables. Keep the filenames and folder structure unchanged unless you also update the references in `index.html`.
